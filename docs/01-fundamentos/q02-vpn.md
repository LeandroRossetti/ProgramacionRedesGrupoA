# 2. ¿Qué es una VPN?

Una VPN (Virtual Private Network o Red Privada Virtual) es una tecnología de redes que permite crear una extensión segura de una red privada utilizando una red pública, como Internet.

Su objetivo es permitir que un usuario pueda conectarse de forma remota a una red privada manteniendo la seguridad de la comunicación. Por ejemplo, un empleado puede acceder desde su casa a la red interna de una empresa mediante una conexión VPN.

Entre sus ventajas se encuentran una mayor seguridad al utilizar redes Wi-Fi públicas, el acceso remoto a recursos privados y la protección de la información transmitida.
