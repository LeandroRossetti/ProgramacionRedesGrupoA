# 5. ¿Qué es un protocolo de comunicaciones?

Un protocolo de comunicaciones es un conjunto de reglas y estándares que definen cómo se transmiten y reciben los datos entre dispositivos en una red.

Qué define un protocolo:

| Elemento | Ejemplo |
| --- | --- |
| Sintaxis | Formato de los datos (estructura del paquete) |
| Semántico | Qué significa cada campo |
| Sincronización | Cuándo enviar y en qué orden |
