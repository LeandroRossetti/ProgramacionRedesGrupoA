# 6. Explique TCP/IP y NetBIOS, resuma sus diferencias

**TCP/IP** es un conjunto de protocolos utilizado para permitir la comunicación entre dispositivos conectados a una red. TCP se ocupa principalmente de controlar la transmisión de los datos y asegurarse de que lleguen correctamente al destino, mientras que IP se encarga del direccionamiento y del envío de los paquetes hacia el dispositivo correspondiente.

Cuando se transmite información, como una foto o un archivo, TCP/IP divide los datos en paquetes que atraviesan distintas capas hasta llegar al destino, donde vuelven a ensamblarse.

**NetBIOS (Network Basic Input/Output System)** es una tecnología que permite que aplicaciones y computadoras dentro de una red local puedan identificarse y comunicarse utilizando nombres. Históricamente fue utilizada principalmente en redes de Microsoft para compartir recursos, archivos e impresoras.

**Diferencias:** TCP/IP está diseñado para permitir la comunicación y el intercambio de datos tanto en redes locales como a través de Internet y utiliza direcciones IP para identificar los equipos. NetBIOS está orientado principalmente a la comunicación y reconocimiento de equipos dentro de redes locales mediante nombres. Actualmente TCP/IP es la base de las comunicaciones en Internet, mientras que NetBIOS es una tecnología más antigua y de uso más limitado.
