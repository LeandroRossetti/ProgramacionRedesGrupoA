**OSPF** (Open Shortest Path First) es un protocolo de enrutamiento dinámico utilizado dentro de una misma organización o sistema autónomo. Los routers que utilizan OSPF intercambian información sobre el estado de sus enlaces para construir un mapa de la topología de la red. Con esta información, cada router utiliza el algoritmo Dijkstra (Shortest Path First) para calcular la mejor ruta hacia cada destino, utilizando un valor denominado costo, relacionado principalmente con el ancho de banda del enlace. Una ventaja de OSPF es que puede adaptarse rápidamente a cambios o fallas en la red y seleccionar rutas alternativas.
