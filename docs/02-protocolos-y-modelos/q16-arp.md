# 16. Explique el protocolo ARP

ARP (Address Resolution Protocol) es un protocolo que resuelve direcciones IP a direcciones MAC en una red local.

Cuando un dispositivo quiere comunicarse con otro en la misma red, necesita saber su dirección MAC (Capa 2), pero solo conoce su dirección IP (Capa 3). ARP resuelve esta traducción.
