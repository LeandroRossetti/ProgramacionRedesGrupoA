# 8. Defina la red según su geografía

1. **PAN (Personal Area Network)**
   - Alcance: aprox. 10 metros.
   - Red personal para conectar dispositivos de un individuo.
   - Ejemplos: Bluetooth entre teléfono y auriculares, conexión USB entre dispositivos, NFC (pagos contactless).

2. **LAN (Local Area Network)**
   - Alcance: hasta 1 km (edificio o campus pequeño).
   - Red de área local que conecta dispositivos en un área limitada.
   - Ejemplos: red de una oficina, red doméstica, red de un laboratorio de universidad.

3. **MAN (Metropolitan Area Network)**
   - Alcance: 5–50 km.
   - Red que cubre una ciudad o área urbana.
   - Ejemplos: red de una universidad con múltiples campus en una ciudad, red de cable de una ciudad, red gubernamental municipal.

4. **WAN (Wide Area Network)**
   - Alcance: ilimitado (país, continente, mundo).
   - Red de área amplia que conecta redes LAN o MAN a larga distancia.
   - Ejemplos: Internet, red corporativa multinacional (MPLS), redes bancarias entre países.

5. **SAN (Storage Area Network)**
   - Alcance: data center.
   - Red dedicada para el almacenamiento de datos.
