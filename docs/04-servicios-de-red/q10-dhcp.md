# 10. Explicar el servicio de DHCP

DHCP (Dynamic Host Configuration Protocol) es un protocolo que permite asignar automáticamente la configuración de red a los dispositivos que se conectan a una red.

Un servidor DHCP puede asignar datos como:

- dirección IP;
- máscara de subred;
- puerta de enlace predeterminada;
- servidores DNS.

De esta manera, no es necesario configurar manualmente cada dispositivo. Cuando un equipo se conecta a la red, solicita una configuración y el servidor DHCP le asigna una dirección IP disponible durante un determinado período de tiempo.
