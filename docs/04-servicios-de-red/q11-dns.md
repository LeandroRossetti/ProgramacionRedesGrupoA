El **DNS** (Domain Name System) es un servicio que traduce los nombres de dominio, como www.hola.com, a direcciones IP que permiten localizar los servidores en una red.
Cuando un usuario ingresa una dirección web, el equipo consulta un servidor DNS para obtener la IP correspondiente y poder establecer la conexión.
Existen servidores recursivos, que realizan las consultas en nombre del usuario, y autoritativos, que contienen la información oficial de los dominios.
DNS utiliza principalmente el puerto 53, generalmente mediante UDP, aunque también puede utilizar TCP en determinadas situaciones.
