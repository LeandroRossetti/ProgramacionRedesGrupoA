# 18. ¿Qué es una DMZ?

Una DMZ (Demilitarized Zone o Zona Desmilitarizada) es una parte de una red que se encuentra separada de la red interna de una organización y que se utiliza para alojar servicios que deben ser accesibles desde Internet.

Por ejemplo, una empresa puede colocar en una DMZ:

- servidores web;
- servidores de correo;
- servidores DNS públicos.

La finalidad es aumentar la seguridad. Si un servidor ubicado en la DMZ fuera atacado o comprometido, la separación dificulta que el atacante pueda acceder directamente a la red interna de la organización.

Generalmente, los firewalls controlan qué comunicaciones pueden realizarse entre Internet, la DMZ y la red interna.
