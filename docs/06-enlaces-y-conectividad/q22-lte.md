# 22. Describir la tecnología LTE

LTE (Long Term Evolution) es una tecnología de comunicaciones móviles utilizada para transmitir datos a alta velocidad mediante redes celulares. Es considerada una de las principales tecnologías utilizadas en las redes móviles **4G**.

LTE permite que dispositivos como celulares, tablets o routers móviles puedan acceder a Internet utilizando la infraestructura de antenas de los operadores de telefonía.

Entre sus características se encuentran:

- alta velocidad de transmisión de datos;
- menor latencia que tecnologías móviles anteriores;
- posibilidad de utilizar servicios multimedia, videollamadas y streaming;
- cobertura en grandes áreas mediante redes celulares.
