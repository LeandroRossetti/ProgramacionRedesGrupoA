# 24. ¿Qué significa aplicar calidad en un enlace MPLS?

Aplicar calidad en un enlace MPLS significa implementar mecanismos de QoS (Quality of Service) para clasificar y priorizar determinados tipos de tráfico según su importancia.

Por ejemplo, se puede dar mayor prioridad a servicios sensibles al retraso, como voz sobre IP o videollamadas, y menor prioridad a otros tráficos como descargas de archivos.

La QoS permite administrar el ancho de banda disponible, controlar la congestión y reducir problemas como la latencia, pérdida de paquetes y variación del retardo (jitter).

De esta manera, MPLS puede garantizar un mejor rendimiento para las aplicaciones más importantes dentro de una red empresarial.
