# 12. Explique las tecnologías Wireless y sus estándares

Las tecnologías Wireless (inalámbricas) permiten la transmisión de datos sin cables, utilizando ondas de radio, infrarrojos o microondas.

| Tecnología | Uso principal | Distancia aprox. |
| --- | --- | --- |
| Wi-Fi | Redes LAN inalámbricas | 30–100 m |
| Bluetooth | Conexión cercana (PAN) | 1–10 m |
| NFC | Pagos, identificación | < 10 cm |
| Satelital | Comunicaciones globales | Global |
| Microondas | Enlaces punto a punto | Hasta 50 km |
| Infrarrojo | Control remoto, breve | < 5 m |

Wi-Fi (802.11) es la tecnología wireless más utilizada en redes LAN. Los estándares principales son 802.11n/ac/ax (Wi-Fi 4/5/6) y se recomienda usar WPA2/WPA3 para seguridad.
