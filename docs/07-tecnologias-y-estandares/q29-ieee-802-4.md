# Explicar el estándar IEEE 802.4 regula la red.

El estándar IEEE 802.4 define una red de área local (LAN) basada en bus con paso de testigo (Token Bus), diseñada originalmente para entornos de manufactura que requieren alta confiabilidad y ancho de banda. 

**Mecanismo de acceso:** 
- Utiliza un token (testigo) que circula lógicamente por un anillo virtual sobre un medio físico de bus, permitiendo que solo la estación que posee el testigo transmita datos, lo que elimina las colisiones. 

**Características técnicas:** 
- Opera típicamente a 10 Mbps (también 1 y 5 Mbps), utiliza cable coaxial de 75 ohmios y admite longitudes de trama de datos entre 0 y 8.192 bytes.

**Estado actual:** 
- Este estándar ha sido abandonado y considerado obsoleto, reemplazado en la práctica por Ethernet (IEEE 802.3) debido a su complejidad y costo de implementación.
