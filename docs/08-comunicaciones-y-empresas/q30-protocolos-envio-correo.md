# 30. ¿Qué protocolos se usan para enviar y recibir correo?

Los principales protocolos utilizados para el correo electrónico son SMTP, POP e IMAP.

**SMTP (Simple Mail Transfer Protocol)** se utiliza principalmente para enviar correos electrónicos, tanto desde un cliente hacia un servidor como entre servidores de correo.

**POP (Post Office Protocol)** se utiliza para recibir o descargar correos electrónicos desde un servidor.

**IMAP (Internet Message Access Protocol)** también se utiliza para acceder al correo recibido, pero permite mantener los mensajes almacenados y sincronizados en el servidor, facilitando el acceso desde varios dispositivos.
