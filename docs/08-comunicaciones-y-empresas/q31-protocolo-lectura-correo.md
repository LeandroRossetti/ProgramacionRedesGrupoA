El protocolo que puede utilizarse para leer el correo recibido es **POP** o **IMAP**. 
POP permite descargar los mensajes desde el servidor, mientras que IMAP permite acceder a ellos manteniéndolos almacenados y sincronizados en el servidor. Por otro lado, SMTP se utiliza para enviar mensajes de correo electrónico, desde un cliente de correo hacia un servidor o entre servidores de correo.
