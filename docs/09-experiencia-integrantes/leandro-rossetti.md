# 33. Experiencia en redes - Leandro

Trabajé administrando redes en varios gimnasios y oficinas, desde la compra del equipamiento, hasta la puesta en marcha y post funcionamiento.

- Configuración de Modo Bridge con el ISP hacia el router del lugar, para luego generar apertura de puertos o configuraciones necesarias para el correcto funcionamiento del sistema y la red.
- Configuración de VPN usando L2TP o utilizando WireGuard y generando certificados y usuarios en el router.
- Configuración de DNS en Cloudflare para sitios web, email, o permitir utilizar a terceros el dominio como por ejemplo para hacer email marketing.
