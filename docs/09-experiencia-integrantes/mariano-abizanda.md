# 33. Experiencia en redes - Mariano

No tengo experiencia laboral previa en redes. Mi experiencia hasta el momento se relaciona principalmente con el uso cotidiano de redes domésticas, como conectarme y conectar distintos dispositivos a una red Wi-Fi y realizar configuraciones básicas del router.

A partir de esta materia estoy empezando a comprender conceptos como direccionamiento IP, modelo OSI, protocolos, routers, switches y subneteo. Mi objetivo es aprender cómo funcionan las redes y poder realizar configuraciones de manera práctica.
